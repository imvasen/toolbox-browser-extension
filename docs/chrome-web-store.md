# Chrome Web Store Listing

Use this copy when creating or updating the Toolbox listing.

## Short Description

Format JSON and XML responses in place with searchable trees and an optional jq workspace.

## Detailed Description

Toolbox turns raw JSON and XML responses into readable, expandable tree views directly at the response URL.

For JSON responses, filter keys and values as you type. When you need a jq query, open a separate Toolbox workspace that keeps the response available for querying. Return to the original response with one click.

For XML responses, inspect a structured tree and expand all nodes when needed.

Choose between Tokyo Night and Catppuccin in the extension popup.

Toolbox does not send response content to a server. The selected theme is stored locally. A response opened in the jq workspace is stored only in browser session storage and is removed when the browser session ends.
