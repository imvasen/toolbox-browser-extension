# Privacy Policy

Toolbox does not collect, transmit, sell, or share personal data or response content.

The extension stores the selected color theme in browser local storage. When you open the jq workspace, Toolbox stores that response in browser session storage so the new extension tab can query it. The browser removes this temporary data when the session ends.

Toolbox uses the `tabs` permission to open the jq workspace and the `storage` permission for the data described above. Its content script runs on pages so it can detect and format JSON and XML response documents.

For Chrome Web Store publication, host this policy at a stable public URL and use that URL in the store listing.
